# v2.1.3：无级变色与独立明暗开关（2026-10-28）

## 只变色，不明灭

1. 打开或导入工程，选择“全局配方”。
2. 预设选“无级变色”，或把效果模式改为“无级变色”。可自选 1～12 种颜色。
3. 选“匀速无缝”，设置每色秒数与流水方向。该模式固定关闭“明暗变化”，不会叠加呼吸或熄灭；单色即为恒定颜色。
4. 需要全部灯面统一时，点“全部改回全局”。本版会保留刚填好的全局设置。
5. 查看预览，再重新生成待测包。旧 .wotmod 不会自动更新。成品恢复中未勾选的模型仍保留原效果，需勾选后重新生成才能修改。

## 呼吸按需开启

“明暗变化”可独立开关。流水呼吸、动态呼吸、百花齐放、波浪、跑马灯取消此项后，都只保留颜色变化；单一颜色时不会产生明暗动画。切换模式不会自行重新打开已关闭的开关。加载带呼吸的预设会加载其对应的明暗设置。

无级变色与流水渐变始终不叠加明暗；呼吸周期、暗相系数、亮灯比例在明暗关闭时不参与动画。方向和每米延迟仍可控制灯段之间的换色先后。

## 无级变色与旧流水渐变的区别

无级变色沿色相的短路径连续过渡，相同 HSV 明度的色标之间保持该明度，避免红蓝直接混色时出现额外的中间降亮。导出序列在色相分段转折处增加关键帧，预览沿用导出序列。

旧流水渐变继续使用原有 RGB 混色，保留旧配方效果。无级变色不会把主动选用的深色、黑色强行提成亮色；不同色相的视觉亮度也不保证相同。若想保持亮色，可使用内置无级变色预设并避免黑色色标。

# WOT 灯效制作器 v2.1.0

## 灯效预设

新增图片中提到的 14 个预设：常亮模式、呼吸模式、梦幻彩虹、一触即发、雨中漫步、涟漪扩散、繁星点点、川流不息、随波逐流、如影随形、正弦光波、旋转风车、七彩瀑布、花开富贵。每个预设可以继续修改并另存；已有同名自定义预设不会被自动覆盖。

这些名称对应本制作器现有的灯效模式。“一触即发”是自动循环的快速波浪，不响应按键或游戏事件；“旋转风车”是多灯段错相闪动，不是真实模型旋转。预设说明和悬停提示中也有标注。

## 单灯面与整模型编辑

上方有三个范围：

1. **全局配方**：设置未使用独立配方的灯面。
2. **套选模型**：保留旧操作，应用时覆盖套选命中的整个模型组。
3. **套选灯面**：只更改套选灯面。点“应用到套选灯面”后生效，再保存或生成。

同一灯面如果在不同外观中完全重合，会同步设置，以免两套效果重叠；相邻不同灯面保持独立。导出时按配方拆分独立模型和序列，二维、三维预览使用同一分组规则。若输入工程中完全重合的外观灯面已有不同配方，生成会提示先统一，避免悄悄叠加。

从旧成品按模型部分恢复时，一个恢复项目可能已经包含多块原灯面；这种情况下不能凭空重新拆回原始分组。包含原工程的成品或原 `.wotlights` 可以保留原灯面粒度。

## 匀速无缝换色

在颜色栏旁的“换色”选择 **匀速无缝**：颜色连续变化，最后一色回到第一色，连续重复的相同颜色会合并，避免在颜色节点停顿。原来的**柔和**曲线仍保留，并作为旧工程默认值。

需要整体同步时，可把方向设置为“同步”。需要同时明暗呼吸时，可选择“动态呼吸”，把暗相系数调到小于 1，并设置呼吸周期。暗相为 0 时呼吸低点仍可能接近黑色；不希望出现黑场可试 0.2～0.4。颜色循环与序列驱动的呼吸使用共同周期；周期太长时会提示调整。原生流水呼吸还涉及游戏着色器，预览不能替代游戏内观察；不同部件的实际同步和空间色带平滑程度仍以游戏为准。

旧工程可以在 v2.1.0 打开。使用了“匀速无缝”的新工程或新预设，需要 v2.1.0 或更新版制作器读取。

## 基础操作

1. 解压便携包，运行“启动灯效制作器.cmd”。选择实际游戏目录，再导入原始涂装或打开工程。
2. 左侧 ☑ 是生成勾选；蓝色高亮是编辑套选。双击或按空格切换勾选，点击灯面或拖框套选；Shift 加选、Ctrl 减选，Alt 框选扩展整模型。
3. 选择预设、调色盘和参数；局部编辑需点击应用。模式未使用的参数会显示为禁用，并保留原值。
4. 可打开三维实时预览，使用流畅、均衡、高画质三档；滚轮缩放、左键旋转、右键平移。预览为近似显示，不执行游戏原生材质。
5. “嵌入可恢复工程”默认开启；生成后可重新导入恢复当时已应用的工程状态。也可点击“保存工程”另存 `.wotlights`。
6. 生成包默认不安装。选择实际客户端后如需自动安装，可自行勾选；游戏内效果和整车兼容仍需实测。
