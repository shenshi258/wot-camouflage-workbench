# RGB 循环与流动彩虹制作工作流

本流程是 [呼吸灯制作工作流](呼吸灯制作工作流.md) 的补充，同时执行 [整车加载兼容性工作流](整车加载兼容性工作流.md)。

## 当前证据范围

2026-10-24，以实际安装的 SFAC105 独立灯效 R3 为输入，制作两个 V1 待测包。目标为 EU 2.4.1.0 #981。源包为 `a0c89e72b080b30042d9f13cef97ec5cba3c06b8be43ab4e8367ee70f416d3fe`。

工程位于 `改造区/SFAC105_RGB彩虹工程`，包含构建脚本、原生程序检查、离屏渲染、最终包校验与隔离运行时测试。**本轮仅离线通过，两个包均未安装、未进行游戏内整车验收。**

## 两种效果的区别

- RGB 循环：各灯面使用同一张恒定相位图。同一时刻的颜色基本同步，随时间循环变化。
- 流动彩虹：每块灯面使用变化的空间相位图，同一时刻不同位置具有不同颜色，颜色随时间移动。
- 原有彩色 emissionMap 仅加明暗变化，不足以实现这两种效果。Blender 的 Hue 动画也不会自动进入游戏。

## 本次原生配方

保持独立模型与 `.seq` 挂载，不替换整车 Compound 材质，不覆盖原生 `.fxo`。

| 属性 | 本次值 |
|---|---|
| fx | `shaders/custom/emissive_playground.fx` |
| animationMode | `2`，核对当前原生枚举为 Pulse |
| useVersicolorMode / usePhaseMap | `true` / `true` |
| g_chromaOffsetGreen / g_chromaOffsetBlue | `2/3` / `1/3` |
| waveLen / speed | `4` / `1/6`，本次实测约 6 秒一轮 |
| g_offsetBlack / g_offsetBlackFwd | `0.12` / `0.12` |
| g_contrast / g_zeroPhaseLum | `1` / `1` |
| g_tint | `1.5 1.5 1.5 1` |
| srcBlend / destBlend | 沿用 R3 的 `3` / `6` |

保留原生变色算法伴随的亮度起伏；不能宣称恒定亮度或纯 HSV 色相旋转。变色分支与普通呼吸分支使用的参数不同，不要把前者的有效性结论无条件套用到后者。

## 资源制作约束

1. 先检查原 emissionMap 是否会滤掉某个颜色通道。本轮创建独立中性 BC3 副本，只转换颜色端点；原透明度块、颜色索引、尺寸、完整 mip 链保持，原车贴图不覆盖。
2. 相位图红通道不要为零：当前原生程序在相位为零时有特殊分支，可能不执行预期的循环。RGB 版采用约 0.5 的恒定相位。
3. 本轮流动版在各灯面的现有 UV 较长轴上设置约 0.1–0.9 的渐变。保留网格和 UV；方向受原图集排布影响，跨 UV 岛或跨灯面无缝流动另做研究，不虚构为已实现。
4. 相位图采用小型 BC3 贴图，保留完整 mip 链。检查 UV 边缘、负 UV、采样和远处 mip 的变化。
5. 同一灯效的两个完整替换包不能并装，也不能与旧版完整皮肤叠装。维持原安装文件名及路径，备份放在活动版本目录之外。

## 验证要求

- 对最终包读取实际材质参数和贴图，而非只测手工设定的预期参数。
- 核对 Pulse、usePhaseMap、useVersicolorMode；使用当前客户端的原生编译程序。用通道偏移实际参与计算的分支做变色检查，并以不启用变色的原生分支作为对照。
- 本轮执行分支 10/11 的 4 个变色像素程序、4 个非变色对照程序，至少覆盖两轮循环、RGB 三种主导颜色、空间差异、稳定 alpha 和最终 24 份灯面材质。
- 离屏像素程序运行未覆盖完整引擎的材质分派、顶点阶段、混合/深度、整车 Compound；验证报告必须保留此边界。
- 最终包重新做全车分组和依赖检查，并运行炮管俯仰、悬挂、开镜/退镜、首次构建、挂载清理的离线回归。运行时模拟通过不能代替实际观察。
- 两个新包的整车状态均从 `not_tested` 开始。哈希、客户端、画质、相关资源覆盖变化后旧结论不沿用。
