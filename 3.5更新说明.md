# 3.5 更新说明 / Release notes

## 中文

- 新增 **复制设置 / 粘贴设置**：复用位置、尺寸、方向、亮度、对比度、透明度、颜色、裁剪、双侧、呈现方式及图案适配等参数。保留目标车辆、素材、承载面选区和客户端；跨车型粘贴后需检查位置。格式或参数无效时不应用。
- 新增 **图案适配**：「等比完整（留空）」保留完整图案，「等比铺满（裁边）」填满选区并裁掉超出部分，「等比重复平铺」保持素材比例重复图案。保留「拉伸填充（旧版）」供旧工程继续使用。
- 平铺的 **横向重复次数** 支持 0.25～16，默认 2；纵向按素材比例计算。每个重复单元独立裁剪，避免从动画图集采到邻帧。密度或网格过大时提示降低次数或减少选区。
- 桌面 AE 窗口在右侧提供复制/粘贴按钮，在 **长宽与贴合** 页提供适配方式和平铺次数；三维预览展开 **缩放与裁剪** 后提供相同入口。
- 等比适配以投影尺寸计算。主动调整独立长宽比例或四角变形仍会改变图案比例；曲面、投影方向与透视也会影响视觉形状。
- 工程、导出预设和新生成的包保存新增参数；读取旧文件默认沿用原拉伸方式。含新增参数的文件请使用 3.5 打开。保留原 35 款预设文件和早期交付。
- 保留 3.4 的亮度 0.01～100 倍、对比度 0～3 倍、透明度 0～100% 调节。此前生成的成品需重新生成才应用新设置。

验证：98 项后台回归、38 项隔离桌面真实界面检查及三维预览交互脚本检查通过；最终便携包使用包内运行环境复核相同后台与界面测试。导出检查使用合成夹具，只验证制作流程中预览/导出网格、参数与资源的一致性。实际运行客户端未确认，未安装或启动游戏；整车加载及实际光效状态为 **not_tested**。此次功能更新不代表此前反馈的游戏内闪烁已修复。

## English

- **Copy / Paste settings** reuses AE position, size, orientation, appearance, crop, mirroring, placement and pattern-fitting parameters. It keeps the destination vehicle, animation, selected faces and client. Check positions after changing vehicles. Invalid data is rejected before applying.
- **Pattern fitting** offers contain (whole image with empty margins), cover (fill and crop edges), aspect-preserving tiling, and legacy stretch.
- **Horizontal repeat count** ranges from 0.25 to 16, defaulting to 2. Vertical repeats follow the image aspect ratio. Each tile is clipped individually to avoid sampling adjacent animation frames. Excessive geometry is rejected with a density/selection adjustment message.
- Find copy/paste in the AE editor's right column and fitting under **长宽与贴合** (Size and fitting). The 3D preview offers both under **缩放与裁剪** (Scale and crop).
- Independent axis scaling and corner deformation can intentionally change proportions. Curvature, projection direction and perspective can also change the visible shape.
- Projects, exported presets and newly generated packages retain these settings. Older files default to legacy stretch; reopen files containing new settings with 3.5. All 35 original preset files and earlier deliveries are retained.
- Brightness (0.01–100×), contrast (0–3×) and transparency (0–100%) remain available. Regenerate previously produced packages to apply changes.

Validation: 98 backend checks, 38 isolated desktop UI checks and preview interaction scripts passed. The portable build repeats the backend/UI suites using its bundled runtime. Synthetic export fixtures check geometry, parameters and resource consistency, not native rendering. The actual running client is unconfirmed; no game installation or execution occurred. Whole-vehicle loading and observed in-game effects remain **not_tested**. These editor features do not establish a fix for the separately reported flicker.
