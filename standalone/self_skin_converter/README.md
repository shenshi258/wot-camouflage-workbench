# 独立涂装仅本车转换器

此目录可单独打包，入口为 `entry.py`，无需运行涂装工作台。`batch_convert.py` 提供同一批处理功能的命令行入口。

普通包和已适配脚本通过每个 appearance 的独立车型数据选择私有模型；不再依赖是否装备官方涂装。车库单独处理，双形态数据分别复制，碰撞和共享车型描述不修改。徽记登记只做受限静态解析；AE 脚本必须与已核对模板的指令、名称和常量逐项匹配，原输入脚本不由转换器执行。

UML 分支将各方案 `swapNPC` 置为 `False`，保留启用状态、白名单、动画和物理配置；不复制 UML 加载器。原车公共覆盖或未知脚本无法仅靠配置确定范围时拒绝转换。原有依赖缺项记录为原有问题，不把配置转换当作资源修复。

后台测试通过标准 `unittest discover` 运行。实际包的 Python 2 字节码模拟、ZIP 与全车网格分组回读、桌面界面检查均不代表游戏验收；所有候选包保持 `not_tested`。

资源图、徽记解析和描述符复制代码来源于本地“涂装条件转换器_批量错误修订”的独立副本；旧版保留。压缩 XML 解析器的 GPL 许可证保留在同目录。详细用户步骤见 `使用说明.txt`。
