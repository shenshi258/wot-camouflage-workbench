本地涂装屏蔽 1.0 · 待实测

用途
保留自己安装的涂装，在选中车型的敌车或队友加载时，改用所选客户端的原版模型与贴图。
自己的车辆与车库外观保留。通过正常 .wotmod 加载；不修改碰撞、车辆性能、点亮、可见性或射击输入。

制作
1. 启动独立程序，选择实际使用的 Wargaming 欧服／美服／亚服客户端目录。
2. 点击“扫描已安装涂装”或“添加涂装包”；也可以搜索车型并双击勾选。
3. 在游戏目录以外生成待实测包。每次输出都在独立目录；不会改写或安装旧涂装。
4. 游戏更新、增加车型或更换资源后重新生成。只保留一份本工具生成的 .wotmod，避免重复脚本和资源。

游戏内设置
需要另外安装原作者的 ModsSettings API 和其依赖 ModsList API；本程序不附带这两个第三方模组。
ModsSettings API 原作者页面：https://github.com/izeberg/modssettingsapi
本机准备时的欧服已发现 1.7.1 与 ModsList API 1.8.0；这不代表其他客户端也已安装。
关闭游戏后，将生成的 local_skin_filter_1.0_pending.wotmod 手动放入实际客户端 mods/<版本号>/。
保留原涂装；在车库“模组设置”打开“本地涂装屏蔽 / Local skin filter”。
主开关控制启用；“敌车使用原版”默认勾选，“队友使用原版”默认关闭；右侧按车型分别勾选。
设置由 ModsSettings API 保存。修改在车辆下次正常加载时生效；建议下一场训练房检查。
缺少设置 API、队伍不明确、观察者或特殊队伍模式时不替换。撤销时只移出本工具生成的这一份包。

支持范围
支持直接覆盖原版车型路径的模型／贴图涂装。原版各部件、LOD、损毁模型以及官方风格中实际存在的模型一并保护。
不取消官方涂装／风格选择，也不保证恢复被其他脚本修改的官方迷彩、徽记或附件。
UML、自有命名空间模型、AE 或第三方脚本额外挂载的光效／模型不保证屏蔽；它们可能需要在原模组内关闭 swapNPC 或单独适配。
不加载、不执行输入包内的脚本；不通过反作弊规避、隐藏、注入或修改游戏程序实现。
着色器保持原版标识。共享着色器／全局材质覆盖和其他模组的加载顺序仍需实际检查。
官方样式、不同画质、特殊车型、战斗刷新与模组冲突未经游戏内验证；本版本不是官方审核通过的模组。

规则与实测
已参考 Wargaming 官方公平游戏规则：https://worldoftanks.eu/en/content/guide/fair-play/prohibited-mods/
离线检查不能保证反作弊零误报。正式长期使用前可将可审阅源码交官方审核；本工具未自动提交或上传。
验证记录中的 whole_vehicle_loading.status 保持 not_tested；文件与脚本检查不代表游戏兼容通过。
请先保存正常基线，在训练房只启用一份本工具包，核对最终 SHA256；分别检查自身、同款敌车、队友、切车、远近 LOD 和损毁状态。
没有已知正常基线或无法实测时保留为待实测。若闪退／整车加载失败，停用该包并记录失败与精简日志，不反复试用同一失败包。
本工具不包含此前 AE 闪烁问题的修复。
