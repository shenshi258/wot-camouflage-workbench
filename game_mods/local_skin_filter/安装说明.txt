本地涂装屏蔽 2.1.2 · 原生界面修订 · 游戏内插件 · 待实测

2.1.1 的空白窗口已从本次欧服日志定位为游戏浏览器拒绝本机页面（418）。
2.1.2 改用游戏原生 Gameface 界面与数据模型，不启动本机网页服务，
不改变浏览器白名单或安全设置。离线检查已完成，实际游戏显示仍待复测。

适配范围
Wargaming 欧服 2.4.1.1 #993、亚服 2.4.1.1 #991 已分别完成离线接口与包内运行检查。
实际整车、游戏画面与其他模组兼容尚未实测。不是反作弊或官方审核通过的承诺。

安装
1. 先关闭游戏。移出旧版 local_skin_filter_1.0_pending.wotmod、local.skin_filter_2.0.wotmod 、local.skin_filter_2.1.wotmod 或 local.skin_filter_2.1.1.wotmod，本工具只保留一个版本。
2. 将本 ZIP 内的 mods 文件夹合并到相应区服的游戏根目录。
   安装结果：mods/2.4.1.1/local.skin_filter_2.1.2.wotmod
3. 需要模组设置 API（ModsSettings API）和模组列表 API（ModsList API）。
   本机准备时的欧服、亚服均已发现 1.7.1 和 1.8.0，不需要再重复安装。
   其他电脑缺少依赖时，请从原作者或官方 Mod Hub 获取；本包没有附带或改写第三方 API。
4. 正常启动对应区服游戏，在车库模组列表打开“本地涂装屏蔽 · 搜索与框选”。

游戏内使用
1. 确认窗口右上角“启用屏蔽”已勾选。窗口使用包内原生界面，不需要桌面工具或联网网页。
2. 搜索框支持车型名称和编号，如 Pz70、AMX、G197；国家下拉框可与搜索一起筛选。
3. 按住鼠标左键拖动矩形，圈选多行车型；按住 Ctrl 拖动可追加选择，Shift 单击可连续选择。
   拖到列表边缘会自动滚动；切换搜索／国家后保留已选车型。也可用“全选结果”选中当前筛选的全部车型。
4. 在“选中车型设置为”选择不屏蔽、仅敌车、仅队友或敌车和队友，点击“应用到已选”。
   “清空选择”只取消选中行，不改变已经保存的屏蔽范围。
   例如：圈选德国车型设置“仅敌车”，再搜索 AMX 并设置“仅队友”，两组范围分别保留。
   若想直接全部屏蔽敌方涂装，点击“屏蔽全部敌车”：它覆盖所有国家／车型，不受当前筛选限制，并启用插件。
   2.0 已保存的车型规则和总开关会保留。
5. 设置自动保存，回到车库等待准备完成提示。插件从当前区服自己的原版 .pkg 生成独立缓存。
   只为检测到原版车型目录有本地覆盖的车型准备资源；无本地覆盖的车已是原版，不复制全游戏模型。
   无需打开桌面转换器，不修改已有涂装包。准备资源需要时间和额外磁盘空间，随需要恢复的车型增加。
6. 准备完成后，在车辆下次正常加载时生效。首次准备后若提示重启，请重启游戏一次。
   本插件不在战斗中强制重建车辆；进入战斗时暂停准备，返回车库后继续。
7. 自己的车和车库外观保持原涂装。这里的“屏蔽”是让敌车／队友恢复原版外观，不让整辆车消失。

保存与撤销
每款车的范围和总开关由模组设置 API 保存，重启后保留；欧服与亚服读取各自的原版资源与覆盖包。
选“不屏蔽”或关闭总开关后，下次正常加载车辆恢复已有模组外观；已经显示的车辆不会被强制刷新。
准备失败会保留原外观，不使用未完成缓存。失败后可将该车改为“不屏蔽”保存，再重新选择范围重试。
卸载时关闭游戏，只移出本工具的 local.skin_filter_2.1.2.wotmod。
若要释放缓存空间，关闭游戏后仅清理本工具自己的 res_mods/2.4.1.1/vehicles/_lsf2 文件夹；保留其他涂装和模组文件。

限制与验证
自动识别原版车型目录中的模型／贴图覆盖。UML／AE／第三方脚本独立命名空间、额外挂载物或全局共享覆盖暂不保证屏蔽。
不修改碰撞、车辆性能、点亮、可见性、射击输入或反作弊机制，不包含此前 AE 闪烁问题的修复。
官方风格、动态附件、特殊战斗模式、不同画质和其他模组冲突尚需游戏内验证。
观察者、队伍不明确和非标准队伍时保持原外观。未来客户端版本需重新核对适配，当前版不为其他版本声明通过。
whole_vehicle_loading.status = not_tested；离线脚本检查不等于游戏兼容通过。
请保留正常基线后在训练房核对自身、同款敌车、队友、LOD、损毁与切车；发生闪退或整车失败时停用本包。
