本地涂装屏蔽 2.1.5 · 欧服／亚服游戏内插件 · 待实测

本版新增
只显示检测到玩家自制模型／涂装的车。按车库定义增加国家／系别、I–XI 等级、轻坦／中坦／重坦／坦歼／自行火炮筛选。
车名采用亚服中文客户端名称；Jg.Pz. E 100、DBV-152 等亚服保留的名称不变。支持“百突”、编号及忽略连接符的搜索。
放大文字，适配不同分辨率，底部固定金色“应用改动”，显示待应用数量及范围，保存后有明确提示。
补齐原版 SD／HD 贴图配对，区分“游戏可读”“需重启游戏”“准备失败”。百突战斗未屏蔽的具体分支仍待日志确认。

安装
1. 先退出游戏，备份并移出旧版 local.skin_filter 或 local_skin_filter 插件，本插件只保留一个版本。
2. 将 ZIP 中 mods、tools 文件夹及“优化缓存占用.cmd”合并到对应区服游戏根目录。
   插件：mods/2.4.1.1/local.skin_filter_2.1.5.wotmod
   可选工具：游戏根目录/优化缓存占用.cmd、tools/OptimizeSkinFilterCache.ps1
3. 依赖 ModsSettings API 和 ModsList API；本机双区已发现 1.7.1／1.8.0，不重复附带。
   其他电脑缺少时请从原作者或 Mod Hub 获取。
4. 启动游戏，在车库模组列表打开“本地涂装屏蔽 · 搜索与框选”。

游戏内使用
1. 勾选右上角“启用屏蔽”，用搜索与国家／系别、等级、类别缩小结果。
2. 左键拖框圈选，Ctrl 拖框追加，Shift 单击连选，列表边缘自动滚动。
   “全选结果”只选当前筛选，切换筛选保留选择。“清空选择”不改变已保存规则。
3. 选择不屏蔽、仅敌车、仅队友或敌我都屏蔽，确认待应用提示，点击金色“应用改动”。
   保存后有明确提示，每款车可有不同范围。旧版规则保留。
   “屏蔽全部敌车”覆盖全部已检测到自制模型／涂装的车型，不受筛选限制。
4. 返回车库等待资源准备。插件从本区原版 .pkg 生成缓存，不改原文件或玩家涂装包。
   只为需要恢复的覆盖车型准备资源；战斗中暂停准备，不强制重建车辆。
5. 若提示“需重启游戏”，等待所需车型准备完成，再退出重启一次。
   文件已生成不代表本次游戏已读取，资源可读后在车辆下次正常加载时生效。
6. 自己的车与车库外观保留涂装。“屏蔽”是恢复原版外观，不是让整辆车消失。
   UML／AE／第三方独立挂载物及全局共享覆盖仍需适配。

优化磁盘占用
退出游戏后，在游戏根目录运行“优化缓存占用.cmd”，无需 Python。
工具只整理本插件 res_mods/<版本>/vehicles/_lsf2 完成清单中的文件，
核对大小、SHA256 后将完全相同的文件改为 NTFS 硬链接共享。
保留原路径、完整模型与 SD／HD 高清贴图，不降低画质，不清空旧缓存，不处理其他模组。
新增资源后可再次运行；已经共享的文件跳过。非 NTFS 或无权限时保留原文件。
按路径相加的“大小”可能不变，释放量以报告和磁盘空闲空间为准。
报告：_lsf2/_storage_report.json。released_file_bytes 表示本次释放的文件数据字节，
实际空闲空间还受簇分配、压缩影响。校验或路径异常的文件跳过并记入报告。
生成后的共享缓存保持不变；需要改素材请在原涂装或工作台操作，不直接修改缓存。

撤销与卸载
取消“启用屏蔽”并保存，在车辆下次正常加载时恢复原有外观。
卸载时先退出游戏，再移出本插件 .wotmod。原玩家涂装包不需要恢复。
缓存及规则保留，方便回滚，占用工具不会清除规则。
