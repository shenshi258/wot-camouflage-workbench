# 本地涂装屏蔽 2.1.5

独立游戏内插件：按车型恢复敌车／队友的原版外观，自己的车保留涂装。旧版规则保留，欧服和亚服分别读取各自的原版资源。

## 选车界面

只列出检测到玩家自制模型／涂装覆盖的车型。按车库原生定义增加国家／系别（合并）、I–XI 等级、轻坦／中坦／重坦／坦歼／自行火炮筛选，与搜索、拖框叠加。Ctrl 追加、Shift 连选、边缘滚动、全选结果和屏蔽全部敌车均保留。

车名采用亚服中文客户端车库短名称，1002 款名称覆盖当前全部 80 款有自定义覆盖的车；来源文件及哈希见 vehicle_names_source.json，不分发 MO 文件。亚服保留的 Jg.Pz. E 100、DBV-152 等名称保持原样，编号显示在小字中，支持“百突”及忽略连接符的搜索。未收录车型回退本地客户端名称。

增大文字，适配 800×600 至 3840×2160。底部固定金色“应用改动”，显示待应用范围及数量，保存后明确提示。虚拟列表只保留屏幕附近的行，拖框计算使用当前行高。

## 高清缓存与占用

旧缓存确认遗漏引擎隐式读取的 _hd.dds，网格与原版逐字节相同，未发现简化几何。本版补齐同目录 SD／HD 配对，缺少配对的旧格式不再复用；已有缓存优先恢复，分别显示“游戏可读”“需重启游戏”“准备失败”。

百突全部 21 个被覆盖模型路径均在映射中。缓存晚于游戏启动是尚待确认的挂载假设，实际战斗原因仍需新版日志和观察确认。有限日志区分替换、未发布和未知路径，不记录账号、玩家 ID 或网址。

安装包附独立“优化缓存占用.cmd”，退出游戏后运行。optimize_cache.ps1 只处理本插件完整清单中的文件，核对 SHA256 和大小后，用 NTFS 硬链接共享相同内容。保留原路径、完整模型和高清贴图，不减少画质，不清空旧代缓存，不修改原 .pkg 或玩家涂装。重复运行跳过已共享文件，新增资源后可再次运行。

越界、重解析点或校验异常的资源跳过；替换前保留恢复文件并校验新链接。工具在游戏外执行，不装入游戏脚本。_storage_report.json 记录本次释放的文件数据字节、共享数和跳过原因。逻辑大小可能不变，磁盘实际空闲空间也受簇分配和压缩影响。生成后的缓存保持不变；素材请在原涂装／工作台修改。

## 实现与验证

使用私有原生 WULF／Gameface 窗口和 ViewModel 指令，selector.py 的 HTTP 预览仅供开发，不打入游戏包。游戏中不创建 HTTP 服务、不导航 CEF、不修改白名单；进入战斗关闭面板，退出释放窗口。

保留原版材质标识、着色器和网格字节，仅隔离可视资源引用。碰撞、点亮、瞄准、输入、网络和反作弊入口未修改。UML／AE 独立挂载及共享全局覆盖仍需适配。依赖原作者 [ModsSettings API](https://github.com/izeberg/modssettingsapi) 与 ModsList API，不重复分发；Packed XML 的 GPLv3 许可保留。

50 项行为测试含 4 项存储共享检查。两区最终 Python 2.7 字节码、原版资源和接口替身完成离线检查；百突／DBV 152 的原生风格、LOD 路径、损毁和范围矩阵，以及其余 80 款覆盖车型的范围矩阵通过。模型／材质描述还原引用后语义相同，网格、SD／HD 纹理逐字节一致，无新增分组问题。最终页面在独立 Chromium 检查七种分辨率、筛选、拖框及指令分支。

实际 Gameface 显示、战斗敌我、Compound 整车、画质和其他模组联用仍待实测，whole_vehicle_loading.status = not_tested。详见 [安装说明](安装说明.txt)。源码测试与构建工具位于 game_mods/local_skin_filter 和 tools。
